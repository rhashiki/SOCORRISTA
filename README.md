# Re.Force - APH

Simulador 3D educacional para treino e memorização de protocolos de atendimento pré-hospitalar em trauma.

Protocolos abordados na Build 1:
- XABCDE
- Escala de Coma de Glasgow
- SAMPLE
- Avaliação secundária da vítima de trauma

O projeto é mobile-first e funciona como PWA em navegadores compatíveis.

> Ferramenta educacional. Não substitui treinamento prático, protocolos institucionais ou orientação profissional.
